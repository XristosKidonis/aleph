# Contenido de Aleph

Esta rama guarda solo datos que la app baja sin actualizarse. No tiene código.

- `historia/hallazgos.json`: las fichas de la pestaña «Hallazgos» de Historia. Se suma una por semana con la rutina
  `herramientas/hallazgos/RUTINA.md` de la rama principal. El formato lo valida `herramientas/hallazgos/validar.mjs`.
- `historia/registro.md`: qué se publicó cada semana, qué se descartó y por qué.
